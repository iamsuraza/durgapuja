# श्री जय दुर्गा पूजा सेवा समिति — वेबसाइट निर्देशिका (Website Guide)

**स्थान:** बहुदरमाई न.पा. ०६, गम्हरिया, भौराटार, पर्सा, नेपाल  
**उद्देश्य:** पावन नवरात्रि पूजा, महाआरती, दान-सहयोग तथा समिति सूचना व्यवस्थापन

---

## 📖 परिचय

यो वेबसाइट **श्री जय दुर्गा पूजा सेवा समिति** को लागि विशेष रूपमा तयार पारिएको आधुनिक, मोबाइल-मैत्री र श्रद्धाभावपूर्ण वेबसाइट हो। 
यसमा कुनै पनि जटिल डेटाबेस (Database) को आवश्यकता पर्दैन। सबै सूचनाहरू, फोटोहरू, क्युआर कोडहरू र समिति सदस्यहरूको नामावली सामान्य फाइलहरूबाटै सजिलै परिवर्तन गर्न सकिन्छ।

## 📂 फोल्डर संरचना (Project Structure)

```text
navratri-website/
├── public/
│   └── images/
│       ├── logo/            <- समितिको लोगो (committee-logo.png)
│       ├── banner/          <- समितिको ब्यानर (committee-banner.png)
│       ├── hero/            <- माता दुर्गाको मुहार चित्र (durga-face.png)
│       ├── qr/              <- eSewa र बैंक QR कोडहरू (esewa-qr.jpg, bank-qr.jpg)
│       ├── committee/       <- समिति सदस्यहरूका फोटोहरू
│       └── gallery/         <- मेला तथा पूजाका फोटोहरू
│
└── src/
    └── data/
        ├── siteContent.js   <- मुख्य ठेगाना, फेसबुक, फोन, इमेल र मन्त्र
        ├── pujaSchedule.js  <- नवरात्रि १० दिनको पूजा तालिका (मिति/समय)
        ├── donation.js      <- eSewa र बैंक खाता विवरण
        ├── committee.js     <- पदाधिकारी तथा सदस्यहरूको विवरण
        └── gallery.js       <- फोटो ग्यालरीको सूची र विवरण
```

## 🛠️ वेबसाइटको विवरण कसरी परिवर्तन गर्ने? (How to Edit Content)

### १. समितिको Logo कसरी परिवर्तन गर्ने?
* नयाँ लोगो फाइललाई `committee-logo.png` नाम दिएर निम्न फोल्डरमा राख्नुहोस्:
  ```text
  public/images/logo/committee-logo.png
  ```
* पुरानो फाइललाई यसले प्रतिस्थापन (Replace) गर्नेछ र वेबसाइटमा तुरुन्तै नयाँ लोगो देखिनेछ।

---

### २. QR Code (eSewa / बैंक) कसरी परिवर्तन गर्ने?
* **eSewa QR कोड:**  
  तपाईंको नयाँ eSewa QR फोटोलाई `public/images/qr/esewa-qr.jpg` मा राख्नुहोस्।
* **बैंक QR कोड:**  
  तपाईंको बैंकको QR फोटोलाई `public/images/qr/bank-qr.jpg` मा राख्नुहोस्।
* **बैंक खाता नम्बर तथा शाखा विवरण सम्पादन गर्न:**  
  `src/data/donation.js` फाइल खोल्नुहोस् र त्यहाँ रहेको खाता नम्बर, बैंकको नाम र शाखा परिवर्तन गर्नुहोस्।

---

### ३. फोटो ग्यालरीमा नयाँ फोटो कसरी थप्ने?
1. नयाँ फोटोहरूलाई `public/images/gallery/` फोल्डरमा राख्नुहोस् (उदा: `puja1.jpg`, `aarti2.jpg`)।
2. `src/data/gallery.js` फाइल खोल्नुहोस् र `galleryImages` सूचीमा नयाँ फोटोको विवरण थप्नुहोस्:
   ```javascript
   {
     id: 6,
     image: "/images/gallery/puja1.jpg",
     title: "महाअष्टमी विशेष महाआरती",
     category: "पूजा तथा आरती",
     date: "२०८३ असोज",
     description: "श्रद्धालु भक्तजनहरूको उपस्थितिमा सम्पन्न सन्ध्या महाआरती।"
   }
   ```

---

### ४. समिति सदस्यहरू (पदाधिकारी) कसरी थप्ने वा सच्याउने?
* `src/data/committee.js` फाइल खोल्नुहोस्।
* त्यहाँ `committeeMembers` सूची देख्नुहुनेछ:
  ```javascript
  {
    id: 1,
    position: "अध्यक्ष",
    name: "श्री [यहाँ वास्तविक नाम लेख्नुहोस्]",
    image: "/images/committee/president.jpg",
    isPlaceholder: false
  }
  ```
* पदाधिकारीहरूको वास्तविक नाम लेख्नुहोस् र `isPlaceholder: false` बनाउनुहोस्।
* फोटो भएमा `public/images/committee/` मा राखी सोही अनुसार नाम दिनुहोस्।

---

### ५. पूजा कार्यक्रम (मिति र समय) कसरी परिवर्तन गर्ने?
* `src/data/pujaSchedule.js` फाइल खोल्नुहोस्।
* प्रत्येक दिनको (प्रतिपदादेखि विजयादशमीसम्म) `date` र `time` मा नेपाली पात्रो अनुसार मिति र समय लेख्नुहोस्:
  ```javascript
  {
    id: 1,
    day: "पहिलो दिन (प्रतिपदा)",
    title: "घटस्थापना तथा शैलपुत्री पूजा",
    date: "२०८३ असोज १७ गते (आइतबार)",
    time: "बिहान ०६:१५ बजे",
    rituals: ["कलश स्थापना", "जमरा रोपण", "दैनिक पूजा", "सन्ध्या महाआरती"],
    description: "..."
  }
  ```

---

### ६. Facebook लिङ्क कसरी परिवर्तन गर्ने?
* `src/data/siteContent.js` फाइल खोल्नुहोस्।
* `facebook` सेक्सनमा गई नयाँ लिङ्क राख्नुहोस्:
  ```javascript
  facebook: {
    pageUrl: "https://www.facebook.com/profile.php?id=61595256714942",
    ...
  }
  ```

---

### ७. सम्पर्क विवरण (फोन र इमेल) कसरी परिवर्तन गर्ने?
* `src/data/siteContent.js` फाइल खोल्नुहोस्।
* `contact` सेक्सनमा गई फोन नम्बर र इमेल ठेगाना सच्याउनुहोस्:
  ```javascript
  contact: {
    ...
    phonePlaceholder: "+977-98XXXXXXXX",
    emailPlaceholder: "durgapuja.gamhariya@gmail.com",
    ...
  }
  ```

## 💻 वेबसाइट चलाउने तरिका (How to Run Locally)

1. **निर्भरता (Dependencies) स्थापना गर्न:**
   ```bash
   npm install
   ```

2. **डेभलपमेन्ट सर्भर सुरु गर्न:**
   ```bash
   npm run dev
   ```
   तपाईंको ब्राउजरमा `http://localhost:3000` मा वेबसाइट खुल्नेछ।

3. **उत्पादन (Production Build) तयार गर्न:**
   ```bash
   npm run build
   ```
   यसले `dist/` फोल्डरमा उच्च गतिको स्ट्याटिक वेबसाइट तयार गर्नेछ, जसलाई सिधै Vercel, Netlify, वा कुनै पनि वेब होस्टिङमा सजिलै राख्न सकिन्छ।
